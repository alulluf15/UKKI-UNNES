# Workspace Guidelines: Modern Web Guidance Default

Setiap kali mengembangkan antarmuka web, styling, atau fungsionalitas front-end pada proyek ini:

1. **Jadikan Modern Web Guidance Sebagai Prioritas Utama**:
   - Selalu rujuk dan patuhi panduan dari skill `modern-web-guidance` untuk semua tugas HTML, CSS, Blade template, form, modal/dialog, animasi, aksesibilitas (a11y), dan JavaScript sisi klien.
   - Gunakan fitur native web modern (seperti HTML5 dialog/popover, CSS modern layout, semantik aksesibilitas) sebelum menambahkan library ad-hoc.
   - Terapkan verifikasi kepatuhan standar modern pada setiap komponen UI yang dibuat atau dimodifikasi.
